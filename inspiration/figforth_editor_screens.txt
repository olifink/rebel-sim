           . DROP ;
: T        DUP C/L * R# ! H 0 M ;
-->


( fig-FORTH EDITOR V2.0 SCR 3 of 6)

  FORTH B/SCR * SWAP B/SCR * SWAP     ( compute 1st buffers)

          LOOP
  DROP DROP FLUSH EDITOR ;
